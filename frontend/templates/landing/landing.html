How it works
Phase 0
Rule Discovery
LLM analyzes the drug and generates probability tables: demographics, AE incidence rates, onset distributions, dose-limiting toxicities, and efficacy parameters.

Daily Simulation
Hazard functions compute daily AE onset probabilities. An observation model separates ground truth from hospital records. Voice Call Live detects AEs via real-time voice interactions and triggers early visits.
