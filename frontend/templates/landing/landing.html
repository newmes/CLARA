How it works
Phase 0
Rule Discovery
LLM analyzes the drug and generates probability tables: demographics, AE incidence rates, onset distributions, dose-limiting toxicities, and efficacy parameters.
Phase 1
Patient Generation
Sample demographics, comorbidities, and baseline labs from the rule set. LLM fills in clinical details and generates patient personas with 7-dimension mood profiles.
Phase 2
Daily Simulation
Hazard functions compute daily AE onset probabilities. An observation model separates ground truth from hospital records. Care AI detects AEs via video calls and triggers early visits.
Input Drug name + Indication ⟶ Output Full trial data (JSONL), CRF tables across 13 domains, SAE reports

Hazard Engine
Math
Mixture-model hazard functions compute daily AE onset probabilities from onset distribution parameters. No fate tables — pure mathematical hazard drives every simulation day. Each AE type has its own onset CDF (Normal, LogNormal, or Uniform), and the engine calculates conditional daily probability given no prior onset.
